# Послание духов

Одностраничный сайт: тёмно-зелёная светящаяся кнопка «ПОСЛАНИЕ ДУХОВ», по нажатию она растворяется, выдаёт случайное предсказание, а затем разыгрывается финальная сцена.

Живой адрес: https://natashakalash-tech.github.io/touch/
Репозиторий: https://github.com/natashakalash-tech/touch (публикуется из ветки `main`)

Файлы сайта: `index.html`, `style.css`, `script.js`. Никаких сборщиков, зависимостей и картинок — вся графика нарисована кодом (CSS-градиенты, тени, inline-SVG).

## Главное ограничение: это реквизит для Instagram Reels

Наташа записывает экран целиком — от нажатия кнопки до полного затухания — и выкладывает в Reels. **Reels зацикливает короткие видео и проигрывает их дважды подряд**, что её не устраивает. Вся финальная сцена существует ровно для того, чтобы растянуть ролик примерно до 25 секунд и дать ему внятную концовку.

**Из этого следует:** длительность финала — не украшение, а функция. Сокращать таймлайн без явной просьбы нельзя. Если правка задевает тайминги, надо сказать, на сколько изменится общая длина ролика.

## Таймлайн от нажатия кнопки

| время | что происходит | где задано |
|---|---|---|
| 0 с | 28 зелёных искр разлетаются из центра кнопки, кнопка растворяется (1.1 с) | `spawnBurst`, `@keyframes dissolve` |
| 1.1 с | послание проявляется (0.9 с), проступает рунный круг | `revealOracle`, `oracle-in` |
| 2 → 7 с | **пауза 5 секунд** — послание просто висит | `HOLD_MS` |
| 7 с | послание размывается и уходит (1 с) | `oracle-out` |
| 8 с | проступает финальная фраза, ровным шрифтом без дрожания (2 с); круг притухает до 30% | `showFarewell`, `farewell-in` |
| 9.6 → 13.6 с | фраза плавно краснеет | `farewell-redden` |
| 13.6 → 18.7 с | три удара пульса | `farewell-pulse` |
| 18.7 с | фраза разгоняется на зрителя до 10x, цвет добирает до чистого `255,0,0` | `farewell-rush` |
| 19.9 с | 64 красные искры по всей середине экрана, круг гаснет совсем | `spawnShatter` |
| ~23 с | искры догорели, остаётся только туман | |

## Ручки настройки

Все ключевые числа вынесены в именованные константы в начале соответствующих блоков.

- **Длина паузы на послании** — `HOLD_MS` в `script.js`. Единственное число, которое Наташа меняет сама. 5000 = 5 секунд; поставить 9000 — весь ролик удлинится на 4 секунды, больше ничего править не надо.
- **Финальная фраза** — `FAREWELL_TEXT` в `script.js`. Сейчас: `ну всё.. иди.. НЕ ЗЛИ ДУХОВ!`
- **Список предсказаний** — массив `predictions`, самый верх `script.js`.
- **Момент наезда и распада** — `RUSH_AT` и `SHATTER_AT` в `script.js`.

⚠️ `RUSH_AT` продублирован в CSS: задержки в `.oracle.farewell.visible` (`farewell-redden 4s ease 1.6s`, `farewell-pulse 1.7s ease-in-out 5.6s 3`) должны в сумме давать то же значение. **Менять эти числа надо парой, иначе наезд начнётся не в такт пульсу.** Синхронизация помечена комментариями в обоих файлах.

## Дизайн-решения

- **Палитра** — тёмно-зелёная с призрачным свечением, задана переменными в `:root` (`--bg`, `--spirit-glow` и прочие). Изначально сайт был коричнево-янтарным; зелёный выбран под «шаманскую» тему. Красный появляется только в финале.
- **Шрифты** — надпись на кнопке идёт системным `system-ui`, а послание и финальная фраза — `Neucha` (рукописный, с нормальной кириллицей). Раньше был `Caveat`, но он слишком узкий и наклонный, длинные фразы читались плохо. `Caveat` оставлен запасным вариантом в `font-family`.
- **Дрожание букв** — каждая буква оборачивается в свой `<span>` с индивидуальным наклоном, смещением и скоростью (`applyShakyLetters`). Разброс сознательно небольшой: наклон ±3.5° у послания. Раньше было ±14° — выглядело неразборчиво. Финальная фраза не дрожит вовсе: она задаётся через `textContent`, без разбиения на буквы.
- **Кнопка на мобильных** сжимается по содержимому (`width: auto`), а не занимает 96% ширины экрана. Раньше текст болтался в огромной плашке. Пропорции держатся вертикальными отступами (`padding: 2.7rem 2.1rem`), соотношение сторон вышло около 1.45.
- **Перенос надписи на кнопке** — `max-width: 8.5em` у `.touch-btn__label` заставляет «ПОСЛАНИЕ ДУХОВ» лечь в две строки. Слова обёрнуты в `.btn-word`, отрицательный `margin-right` компенсирует хвостовой `letter-spacing`, иначе текст уезжает от центра.
- **У рунного круга нет `drop-shadow`** — и добавлять не надо. Светящаяся тень на вращающемся SVG давала на мобильных браузерах артефакт: на миг проступали границы квадратной области отрисовки, что читалось как рамка у правого и нижнего краёв экрана. По той же причине `backdrop-filter` отключается у кнопки во время растворения.
- **Уважается `prefers-reduced-motion`** — при включённой у пользователя настройке «меньше движения» искры, туман, вращение, пульс и наезд отключаются, но сам сценарий и покраснение работают.

## Как публикуется

Наташа не открывает папку в редакторе и не пользуется терминалом или GitHub Desktop. По слову **«выложи»** правки надо закоммитить и отправить самому:

```
git add -A && git commit -m "описание на русском" && git push origin main
```

Ветку не создавать: GitHub Pages публикует из `main`, любая другая ветка просто не задеплоится. Объяснять результат бытовым языком, без терминов.

**Кеш.** При каждой правке `style.css` или `script.js` надо поднимать номер версии в ссылках внутри `index.html` (`style.css?v=12` → `?v=13`), иначе браузер возьмёт старый файл. Но саму `index.html` GitHub Pages отдаёт с десятиминутным кешем, обойти это со стороны сайта нельзя — поэтому проверять правки надо по ссылке с цифрой на конце: `https://natashakalash-tech.github.io/touch/?13`. Это надёжнее, чем просить обновить страницу.

**Правки вручную.** Иногда Наташа сама меняет фразы в `script.js` через Блокнот и предупреждает об этом — в таком случае надо перечитать файл, чтобы не затереть её текст. Ей заранее сказано: только Блокнот, не Word (Word подменяет прямые кавычки на «ёлочки» и ломает скрипт), и внутри фразы кавычки `"` использовать нельзя.
